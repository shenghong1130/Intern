TonyPi 17 cm 直接任务决策树

本页对应当前代码。地图、Tag 世界坐标、初始定位、屏幕检测、左上 Tag 绑定、FPGA 分类和 Worker 协议保持不变；定位成功后的任务层改为单一 17 cm 目标。

核心边界：没有 34 cm 安全接近点，也没有 15 cm 二次对准。到达 17 cm 后用一帧确认当前 Tag 与绑定屏幕，然后只前进一次 3 cm；前进后立即拍照、FPGA 分类，并按结果结束或换花。

2. 唯一 17 cm 位姿

面判断

Tag 四角固定 X 表示西/东面，固定 Y 表示南/北面；Tag 相对所属四方形中心的符号决定具体一面。法向严格量化为四个轴向。

基础点

face_center = 整个建筑面的中心
base_17 = face_center + normal × 17 cm

Tag 只选择建筑面，不用单个 Tag 中心生成目标。

身体目标

screen_left = (normal.y, -normal.x)
lateral = sensor_left_offset
          - left_hand_body_offset
task_target = base_17
            + screen_left × lateral
建筑面外法向17 cm 基础位置最终身体 yaw
西面(-1, 0)(x_min - 17, center_y)0°，朝 +X
东面(+1, 0)(x_max + 17, center_y)-180°，朝 -X
南面(0, -1)(center_x, y_min - 17)+90°，朝 +Y
北面(0, +1)(center_x, y_max + 17)-90°，朝 -Y

3. 目标选择与导航

选择目标：只考虑非终止目标；用最新 pose 到 task_target_xy 的欧氏距离排序，距离相同按 screen_id/tag_id 升序。
锁定：导航途中看到其他 Tag 只更新几何绑定，不切换目标、不分类。
普通导航：40 cm 范围外保留 action planner、A*、障碍膨胀和全部代价。
近目标直达：40 cm 范围内先检查窄通道；只忽略当前锁定目标建筑产生的膨胀代价，真实占用、其他建筑和动态障碍仍然阻断。通道清晰时优先直走、再侧移，并用小步收尾。
动作偏好：提高转向固定代价、角度代价、连续转向和反向转回惩罚；直走/侧移不可行或避让真实障碍时仍允许转弯。
代价保留：静态/动态障碍、膨胀、cost、A*、action planner、碰撞和近墙恢复继续工作。
近墙例外：只在当前目标锁定、处于最后接近范围且窄通道确认无真实障碍时抑制普通近墙恢复；其他导航继续使用原保护。
路径无法安全到达：按现有目标重试机制记录失败，本轮不拍摄、不前进 3 cm、不换花。

7. 安全模式、失败与调试

dry-run

不操作相机、动作或 Worker；日志记录计划中的 17 cm 坐标、yaw、目标视觉绑定条件和 3 cm 专用动作。

skip-change

真实定位、导航和 FPGA 识别；不执行 3 cm 动作，不举手，不发送 Worker 请求。

失败

视觉或动作失败进入现有目标重试。超过上限才终止失败；所有目标失败进入 MISSION_FAILED，不冒充完成。

Dashboard

显示唯一 17 cm 目标、目标 yaw、到达标志、实时 Tag/屏幕绑定、FPGA 结果、视觉授权、3 cm 动作与 Worker 响应。地图不再画黄色 34 cm 点。

Current target/recovery invariants (2026-08)

Atomic target: TargetGoal owns screen_id, tag_id, anchor_xy, goal_xy, desired_yaw and generation_id. Motion and arrival both validate it against map.screens.
Tag vs classifier: a live TargetTagConfirmation is retained independently. Classifier connection/timeout/5xx errors enter TARGET_CLASSIFICATION_WAIT; they never mean that the Tag disappeared and never set MISSION_FAILED.
Pan observation: the frame captured at the successful pan is consumed for binding/classification before recentering. Retries return to that pan.
Interior recovery: candidates are sampled only inside the configured inward field margin, require obstacle clearance and a safe body-axis L path, preserve current yaw, and resume the original TargetGoal generation.
Dashboard: target anchor, actual navigation goal, recovery waypoint and planned path have separate markers using the same world-to-map transform.
