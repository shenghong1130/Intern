TonyPi 当前完整决策树

依据当前 robot_tonypi 源码和最终合并配置整理：从启动定位、目标选择与导航，到 Tag/Screen 确认、FPGA、两次 NFC 上限、目标重获和任务终止。

坐标约定：场地图左上角为 (0, 0)，世界 x 向下、y 向右；地图显示与导航共用同一坐标变换。

流程/状态判断/门控成功/完成恢复失败/有界出口外部 I/O
业务边界：实体 Screen/Tag anchor 与机器人 task target 是不同点。导航目标为距对应面 20 cm、横向偏移 -1 cm 的 task target；确认确需换花后才执行既有 10 cm final forward。
CHANGED 是终态
NFC ACK 成功，或 ACK 失败后 FPGA 确认已是目标花，立即结束当前 Screen；不再校准、靠近或 Attempt2。
定位成功 ≠ 当前目标重获
错误 Tag 可以更新 RobotPose，但 required-target 搜索必须继续，直到当前目标 Tag 与同 ID Screen 绑定。
Attempt2 有唯一入口
仅 Attempt1 失败、retreat 后重获当前目标，且最新 FPGA 明确 flower != target 时允许。
局部恢复有界
NFC target reacquire 最多 3 轮；NFC 最多 2 次物理 Attempt，不会循环到全局 timeout。

6. Final forward、NFC Attempt1 与 deadline

物理接近

10 cm final forward 为 go_forward_one_step ×2；只在 FPGA 明确当前花不是目标花时执行。

授权

NFC 前检查目标、绑定、分类、到达和授权；流程为 stand → lift_left_hand → recheck → send_request → finally stand。

单次 deadline

每个 Attempt 使用新 seq，retries=0；scan/Attempt hard deadline 均为 15 s，完整响应等待 1 s。

响应匹配

seq 与 worker/screen 必须匹配；timeout、invalid response、可恢复 I²C 异常进入上层物理 retry。

Attempt1 请求

ACK success？
→
CHANGED立即终止 Screen
→

Attempt1 fail / timeout → stand → 后退 10 cm → full relocalize → 重获当前目标，而不是原地重发。
retreat 使用 back_fast，模型单次 2.5 cm，10 cm 为 4 cycle；本 episode 只做一次。
ACK success 后绝不执行 target recalibration、retry reapproach 或 Attempt2。

7. Reacquire current target：定位与目标重获分离

reacquire cycle 1..3
→
required-target full pan
→
看到哪个 Tag？
只看到其他 Tag → 可更新 RobotPose → target_reacquired=False → 不停止 pan，继续剩余角度。
目标 Tag 但无同 ID Screen binding/fresh classification → 目标尚未重获，继续有界搜索。
目标 Tag + 同 ID Screen 绑定 → target_reacquired=True → 停止专用扫描并读取该 Screen FPGA。
3 轮仍未重获 → TARGET_REACQUIRE_FAILED → GAVE_UP 当前交互 → 离开并选择下一个目标。
例：目标 Screen24，pan=100 看到 Tag15。Tag15 可更新 Pose，但不能结束 required-target 搜索；继续扫描，直到 Tag24+Screen24 或 3 轮耗尽。

8.1 所有交互终态

状态来源后续
ALREADY_TARGETFPGA 明确当前花就是目标花。不 final forward、不 NFC；完成并 next。
CHANGEDNFC ACK 成功，或 ACK 失败后当前目标 FPGA 确认已换好。终止交互；若仍在 close pose 则 retreat，再完成/next。
TARGET_CLASSIFICATION_WAIT / DEGRADED初次目标分类服务不可用或结果无效。保留当前目标并按配置间隔重试；不清 Tag 确认、不进入 NFC，也不结束 mission。
FAILED / GAVE_UPAttempt2 失败，或 target reacquire 3 轮耗尽。Screen 标记 FAILED 并加入本进程 NFC give-up 集合；离开并继续，mission 不退出。

post-interaction retreat：恢复站立，按需后退 10 cm，再 full-pan relocalize。物理后退只执行一次；定位失败进入既有恢复，不重复盲退。
