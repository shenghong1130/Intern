0. 全局主流程

2. 目标选择：nearest-first + orientation penalty

输入是当前 Pose 和所有 Screen。合法 locked target 始终优先保持；否则排除 completed、temporary failed 和 NFC gave-up，距离统一量到 25 cm interaction_target_xy。只有落入最近距离窗口的候选才比较朝向。

shortlist: distance ≤ nearest_distance + 25 cm
behind_turn = max(0, |bearing_error| − 90°)
orientation_penalty = min(25 cm, behind_turn × 0.20 + final_yaw_error × 0.03)
score = distance + orientation_penalty

5. 到点与 Target Tag / Screen 确认

A* 与真实执行都要求 XY + yaw 到达。由于步态误差，XY 已合格但 yaw 略超差时允许既有 final micro-turn 补偿；规划器本身仍不能忽略 yaw。到点坐标也不会自动授权 FPGA/NFC，必须重新获取当前目标视觉证据。

8. Mission Complete / Timeout

所有目标进入完成或既有终态后正常完成；任意循环发现 deadline 耗尽则立即走既有 timeout/safe-stop。临时失败目标仍按当前 global recovery 规则释放和轮换，不改变其业务意义。
