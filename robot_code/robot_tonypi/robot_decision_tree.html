   ├─ 无帧 → capture_failed

   ▼ 至少一个 Tag

普通位置动作

back_fast ×2（模型约 5 cm），再按左右 fast-turn 的配置 yaw 计算约 45° cycle。专用转向不走 LOW confidence batch cap。

墙边动作

用地图 clearance 选安全的左/右横移；不优先做大幅原地转身。

成功

中央视角获得可信 Pose；立即清零 no-tag counter，保留当前目标并回到导航。

耗尽

3 轮仍完全无 Tag；记录 no_tag_recovery_exhausted 并进入全局恢复。没有无限左右摇头。

代码参考：recover_from_no_tag_if_needed()、no_tag_recovery_turn()、choose_near_wall_lateral_direction()。

物理 yaw

configured_yaw_deg 来自 motion.actions.*.yaw_deg，供硬件、里程计和 watchdog 使用。

规划 yaw

15° bin 下，物理 -18° 必须跨 2 bin，所以 planner_yaw_delta_deg=-30°。它只代表离散搜索状态。

距目标 ≤15 cm 时只执行单周期。普通 REVERSE 仅允许在最终目标 5 cm 内、目标在后方、确实缩短距离且后方通道安全时使用。

代码参考：plan_motion_actions()、execute_motion_astar_action()、post_action_relocalize()。

  • target_distance_cm=25.0 不变；final forward 的实体序列和模型都改为约 20 cm。
  • 其他 Tag 可以更新 Pose，但不能算“当前目标已重获”。
  • CHANGED 是终态；Attempt 2 只能在 Attempt 1 失败且 fresh FPGA 明确仍非目标后执行。
  • 进入过近距离交互位后，保持既有一次 10 cm retreat 和重新定位。

25–28. Recovery 唯一入口与去向

恢复触发机器人实际动作成功 / 失败 / 最大次数之后去哪目标
无 Tag 恢复连续 2 次完整扫描零 Tag墙边安全横移；否则后退 5 cm + 向内身体转 45°；中央复拍可信 Pose 成功；3 cycle 仍零 Tag 耗尽导航 / 全局恢复保留
靠墙恢复靠墙、通道失败或局部恢复入口安全后退 → clearance 最优横移 → 最后小转；每步定位back 3、lateral 2、总动作 12；离墙或 clearance 改善成功重规划 / bounded escape / 导航失败保留
碰撞/前进停滞恢复前方障碍或前进视觉/位姿证据触发，且配置启用有界后退并定位最多 3 次定位；独立使用 collision 参数恢复导航或失败调度通常保留
全局恢复NO-TAG 耗尽或全部目标临时失败完整定位；near-wall 或室内安全 waypoint；无 Pose 时有界搜索每次一轮，受各子上限与全局 timeout 限制释放临时失败并重新选目标按调度规则
目标临时轮换重复同类规划失败达到 3不做交互动作，选择其他目标全部都临时失败时升级全局恢复选目标暂时释放
