# 智能机器人及场地架构说明
## 1 障碍
场地共设置9个障碍物，障碍物尺寸为`25.5*25.5*41.5(cm)`，壁厚5mm。
目前障碍物位置与原场地相同，统一设置朝向为（俯视）逆时针方向，最小号朝北。
单块障碍物面板的平面图如`side_draft`所示，注意屏幕在右的表面为外表面，加工时可将该表面所有孔加工为沉头孔
### 组装
8根25cm，4根40cm铝合金条共同构成单个框架，连接处插入三角连接件，用无头圆螺丝固定。
上下正方形各边的朝外侧分别插入2个元宝螺母。四块面板的上下4孔分别与螺母对准（可用螺丝刀定位），用5mmM5沉头螺丝固定。
依次安装四块面板，每块板长于框架的部分统一留在右侧，与后一块板的厚度相同。
### 电路组件
红色大电路板是网关组件gateway，绿色长条电路板是worker，绿色小电路板是RFID元件，另有RFID线圈和LED灯组（WS2812）、液晶屏幕(TJC-T1C)
每块障碍板配置一个worker,一套RFID,一个灯组和一块屏幕，但**一个障碍物各板共用一个网关**
* 网关：安装于右下方，网口朝下。板外侧用8mm及以上M2.5螺丝穿过板，内侧用M2.5铜柱连接压紧，铜柱上放置电路板，用4mm及以上8mm以下M2.5螺丝固定
* worker：安装于左下方，无朝向限制。固定方式同网关
* RFID：安装于左侧中部，注意**使孔位于下侧安装，电路板向上延伸，否则会卡住网关**。板外侧用8mm及以上M2螺丝穿过板，内侧用M2铜柱连接压紧，铜柱上放置电路板，用6mm及以下M2螺丝固定
* 线圈：在RFID上方粘贴在表面，无朝向限制，线圈表面向外，注意**位置适当靠左，以给框架留出空间**
* LED：安装在线圈以内，由于目前设计图案全都中心对称，无朝向限制，灯朝板，板外侧用10mm及以上M2.5螺丝穿过板和灯组，内侧用M2.5螺母压紧
灯组默认蓝灯频闪，当机器人尝试修改屏幕成功时，灯组显示绿色圈；当修改失败时，显示红色叉；当机器人发送的指令不合法（如，密码错误）时，显示黄色框
* 屏幕：安装在右上方，手写数字的方向就是屏幕方向，板外侧用10mm及以上M2.5螺丝穿过板，先用M2.5螺母压紧，再放置屏幕，再用M2.5螺母压紧（为了防止屏幕凸出表面
屏幕项目文件未改动。如需更换屏幕，需单独进行烧录：用USB-TTL线连接屏幕与电脑，下载USART HMI，确认连接屏幕并打开代码后，**在参数设置（第二栏）更改`sys0`参数为屏幕编号**，保存，最后点击“下载”并等待。
* 线路：网关用串口线依次串联各个worker一圈后回到网关，并连接网线；worker剩余的4线大串口连接屏幕，4线小串口连接RFID，3线杜邦线接口连接LED；RFID的圆心金属接口连接线圈。注意线圈要套入LED的杜邦线
* 代码：用USB线分别连接gateway和worker，用指令分别烧录同名目录代码

## 2 起点
共设置8个起点，起点面板平面图如`start_draft`所示，无朝向限制
### 固定
通过宽3cm，带蝶形头螺丝的金属固定件固定，每块板配置2个。下方M8孔与固定件上蝶形头螺丝**对侧**的孔连接，可使用8mm及以上M8螺丝及螺母。（目前是使用了10mm的M5螺丝，固定件内外各一螺母进行固定，但不是标准方法。另外注意不要选用过长的螺丝，会损伤场地边缘）
每个固定件开口朝下，插入场地边缘，再用蝶形头螺丝拧紧。注意为了避免螺丝伤人，可以套上保护套。
另外3cm开口紧固件无法在两场地中间的金属围挡固定，目前采用粘贴，可以考虑更换为4cm开口
固定完成后，板在场地内侧，朝向场地的一侧无任何元件，所有电路板都在朝场外侧场地边缘以上的部分，连接件横跨场地边缘，螺丝在场外
### 电路组件
每板配置一个黑色大电路板，是总控组件start，另有一个RFID元件和线圈，一块圆形LED灯组
* start：网口朝板外侧面，固定方式同网关
* RFID：注意使孔朝向内侧安装，电路板向外延伸，否则会卡住starter
* 线圈：一切相同
* LED：安装在线圈以内，无朝向限制，注意**灯朝外，背向板**。板外侧用8mm及以上M2螺丝穿过板，内侧用M2铜柱连接压紧，铜柱上放置电路板，用6mm及以下M2螺丝固定
灯组内圈默认紫色频闪，当机器人注册成功时，亮绿色；外圈默认灭灯，上位机确定起点后，相应队伍的起点会亮起队伍颜色的灯带。如果打开了自由起点模式，所有起点亮白灯
* 线路：网关小串口连接RFID，杜邦线口连接灯组，并连接网线
* 代码：用USB线连接start，用指令烧录同名代码，注意，**每次烧录之前需要根据起点的编号，更改源码内的起点编号，可能还需要更改ip地址和MAC地址**

## 3 上位机与定位
上位机的端口、界面都沿用了之前的设计
控制面板新增了一些控件：
* 可以选择是否允许触摸屏幕更换花色
* 可以选择固定分配起点或任意起点，在固定分配起点模式下，需要通过本机申请起点，机器人才能去相应起点注册，无法在未申请的起点注册
* 用表格列出了各队伍及屏幕的状态
* 地图面板各屏幕排布改为实际方向
* target rule请保持target only

目前设计的的比赛流程为：
* 上位机分配足够数量的起点
* 根据现场组织，各队伍选择自己的起点，并用机器人刷起点卡注册，将机器人和队伍绑定
* 比赛开始后，机器人通过刷相应障碍物卡获取得分

定位模块：
场地上方安装了两台摄像机，分别负责半场的拍摄定位。摄像机的相应路由位于教室入口
在机器人头上贴上相应编号的tag，对应规则为100+(id-1)%20+1，即2号机器人贴102，5号贴105，……20号贴120，21号贴101。机器人进入场地后，地图上即用数字圈动态显示机器人的位置，每1.5s刷新一次定位。
障碍物上方靠近原点的角落贴了91~100号tag，与障碍物编号对应。未来若需要移动障碍物，可以用程序快速生成新障碍物的侧面tag位置
地面tag的位置也可用程序生成（不过有些tag被遮挡测不出），误差约10cm。不过目前的tag数据是手动测量出来的，所有tag数据均保存在`tag_positions.py`中，使用方法等同之前的`load_pos.py`

## 4 机器人
在初始化机器人系统时，应当按照原机器人的方法，取下sd卡并在电脑上刷写镜像。镜像中包含了jupyter，机器人联网（应当也设置在镜像里了）后，可以通过`192.168.31.2xx:8888`访问jupyter编写代码，xx为机器人两位编号。
安装后的机器人可以进一步安装机器人调用库robotall，方法是上传整个文件夹，执行以下指令安装：
```
cd (目录)
pip install .
pip install smbus2
```
库的readme中包含了各个函数的详细用法，涵盖了运动控制、拍摄照片、发送更改消息等所有功能
机器人摄像头可以手动调焦，当拍摄画面模糊时，可以旋转头部摄像头调整
